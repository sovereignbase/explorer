    • Explorer

    Class Explorer

    Provides authentication, encrypted object storage, and access to the database's synchronized entries.

    Maintains the authenticated database context and exposes static methods for managing stored objects, observing entries, and applying remote deltas.

    Staticapply

    • apply(data: unknown): void

      Schedules the application of a synchronized Explorer delta.

      Recognized deltas are forwarded to their corresponding entries list. Invalid or unrecognized delta types are ignored.

      Processing is scheduled in a microtask and is not awaited by the caller.

      Parameters

      • data: unknown

        The delta to apply.

      Returns void

    Staticauthenticate

    • authenticate(
          dataPIN: string,
          storageURL: `http://${string}` | `https://${string}`,
          setupParams?: Readonly<
              { bindingStorage: DeviceBindingStorage; credentialName: string },
          >,
      ): Promise<AuthenticationResult>

      Authenticates a database using a data PIN and device-bound entropy.

      Derives the credential and database identifiers from cryptographic secrets. When setup parameters are provided, creates and stores a new credential. Otherwise, loads the existing credential.

      Records the authenticated credential in the database's credential list.

      Parameters

      • dataPIN: string

        The PIN used to derive the credential and database secrets.

      • storageURL: `http://${string}` | `https://${string}`

        The base URL used to access persisted database objects.

      • OptionalsetupParams: Readonly<{ bindingStorage: DeviceBindingStorage; credentialName: string }>

        Optional parameters for creating a new credential.

      Returns Promise<AuthenticationResult>

      The authentication result.
